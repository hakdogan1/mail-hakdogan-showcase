# Mail Hakdogan

A public project overview for the temporary QA mailbox service.

## Live service

- [mail.hakdogan.com](https://mail.hakdogan.com)

## Purpose

- Disposable mailboxes for registration and email-verification testing
- Manual username or random mailbox generation
- Inbox refresh and message reading through the cPanel IMAP bridge
- Copyable test email addresses

The production source repository is private. This showcase repository intentionally contains documentation only and no application source code, credentials, IMAP passwords, or deployment secrets.
